Wick 0.2.0 adds an app uninstaller, explains the space Windows doesn't show you, uses graphics cards better, and
fixes a long list of freezes and rough edges. Updating keeps your settings and History.

## New

- **Uninstall apps you no longer use.** Clean Up › Apps lists installed apps with their size and when you last
  opened them, with the ones you haven't opened in six months at the top. Uninstall runs the app's own
  uninstaller, then moves the folders it left behind to the Recycle Bin, so you can still get them back.
- **App Leftovers** finds folders in AppData and ProgramData that belong to apps you removed long ago. Nothing is
  selected for you, since Wick can't always be sure a folder is unused.
- **What "Everything else" is.** On Home, Explain shows the space outside your folders: the hibernation file,
  page file, restore points and WSL or Docker disks on Windows, and system logs, package caches, Flatpak and
  Snap on Linux, each with a safe way to free it.
- **A heads-up when a drive is almost full.** Wick can let you know, or also clear the app caches it marks as
  safe (Settings › When a drive is almost full).
- **Ctrl+K** opens a command bar: type to jump to any page or Clean Up tool, or run an action.
- **Smaller files or faster?** Wick asks once, suggests an answer for your computer, and sets JPEG XL effort and
  a new processor speed option for videos. Both can be changed later in the compression options.
- **Stop any task** from the running-tasks panel in the sidebar.
- **Scoop:** `scoop bucket add wick https://github.com/Lanntern/Wick`, then `scoop install wick`.
- **AI assistants** can now look through Clean Up's findings too (read-only).

## Better

- **Graphics cards:** NVIDIA encodes use a full-resolution first pass, temporal AQ and B-frame references; Intel
  uses look-ahead; AMD switches from a fixed QP to quality-based rate control with pre-analysis. Each is only
  used if your card and driver accept it.
- **Duplicates are found several times faster**, hashing files in parallel with BLAKE3. Hard drives are read
  one file at a time instead, which is faster for them.
- **FLAC** files come out about 1% smaller.
- **Safer previews and scans:** thumbnails, previews, Broken Files and Similar Photos decode files in a separate
  process with fewer rights, so a damaged or malicious file can't take Wick down with it.
- **Quitting never freezes**, even with work running, and nothing is left half-done.
- **Faster start-up**, and the first thumbnail no longer waits.
- **Every dialog** now has the same layout and button order, and settings and tooltips say less, more plainly.
- **Tooltips** appear as a card under the control instead of following the pointer.
- **Undo** is offered right after a job, and file types you've turned off can be turned on from the result.
- **Compress Apps** shows sizes, estimates and per-folder settings more clearly, with optional community results
  from CompactGUI.
- **Bundled tools updated:** libjxl 0.13.0, gifsicle 1.97 and Pandoc 3.14.

## Fixed

- Some videos were rejected as "Output video has decoding errors" when FFmpeg only printed a harmless message
  that the original also produced.
- Large Metadata scans could make the window stop responding.
- The running-tasks button didn't shorten when the sidebar got narrow.

## When something goes wrong

- If Wick closes unexpectedly, it says so at the next start and offers to report it, with the details attached.
- Settings › Report a Problem copies the diagnostics and opens the bug report form.
- The log now records what failed and why, instead of every routine step.
